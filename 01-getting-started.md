# Getting Started

## What Is Git?

Git is a version control system used to track changes to files over time.

It keeps a history of changes so you can see what was changed and when.

## What Is GitHub?

GitHub is a platform where Git repositories can be stored online.

It allows people to work on projects, track changes, review contributions, and collaborate with other people.

## What Is a Repository?

A repository is the project space on GitHub.

It contains the project's files and their revision history.

A repository can contain documentation, code, images, configuration files, and other project files.

## What Is a Branch?

A branch is a separate version of a repository where you can work on changes without changing the main branch immediately.

The main branch is usually called `main`.

## What Is a Commit?

A commit is a recorded snapshot of changes made to files in a repository.

A commit also includes a message describing the changes.

## What Is a Pull Request?

A pull request is a request to review changes made on one branch before merging those changes into another branch.

Pull requests allow changes to be reviewed and discussed before they are merged.

## What Is an Issue?

An issue is used to track a task, problem, question, or idea related to a repository.

## What You Need

You need:

* A GitHub account
* A web browser
* An internet connection

## Signing In to GitHub

### Step 1: Open GitHub

Open your web browser and go to GitHub.

### Step 2: Sign In

Select **Sign in**.

Enter your GitHub username or email address and password.

Complete any verification GitHub requests.

After signing in, GitHub will take you to your GitHub account.

You are now ready to create your first repository.
