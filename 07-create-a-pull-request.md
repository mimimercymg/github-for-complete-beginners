# Creating a Pull Request

A pull request is a request to review changes made on one branch before merging those changes into another branch.

Pull requests are commonly used when people collaborate on GitHub projects.

## Step 1: Make Sure Your Changes Are Complete

Before creating a pull request:

* Make your changes
* Review your changes
* Commit your changes

For this guide, the working branch is:

`add-github-workflow`

The branch we want to merge into is:

`main`

## Step 2: Open the Pull Request

After making changes on your branch, GitHub may show an option to compare your branch and create a pull request.

You can also open the **Pull requests** tab near the top of the repository and select **New pull request**.

## Step 3: Check the Branches

Check the two branches shown on the pull request page.

The **base** branch should be:

`main`

The **compare** branch should be:

`add-github-workflow`

Make sure these are correct before continuing.

## Step 4: Review the Changes

GitHub will show the differences between the two branches.

Read through the changes and make sure they are correct.

## Step 5: Add a Title

Enter a short title that explains the change.

For example:

`Add beginner GitHub workflow`

## Step 6: Add a Description

Explain what you changed and why.

For example:

`This pull request adds a beginner-friendly explanation of the basic GitHub workflow.`

## Step 7: Create the Pull Request

Select **Create pull request**.

The pull request is now open and ready to be reviewed.

## Why Pull Requests Matter

A pull request gives people a place to review, discuss, and improve changes before they are added to another branch.
