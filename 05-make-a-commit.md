# Making Your First Commit

A commit is a recorded snapshot of changes made to files in a repository.

A commit also has a message that explains what was changed.

## Step 1: Open a File

Open a file in your repository.

Select the **pencil icon** to edit the file.

## Step 2: Make a Change

Add, remove, or change some text in the file.

For example, add this sentence:

`GitHub allows changes to be reviewed before they are added to the main branch.`

## Step 3: Preview the Change

Select **Preview** to check that the formatting and content look correct.

## Step 4: Commit the Change

Scroll to the **Commit changes** section.

Enter a short message describing the change.

For example:

`Update beginner guide`

## Step 5: Save the Commit

Select **Commit changes**.

GitHub will record the change in the repository history.

## Understanding Commit Messages

A commit message should briefly explain what changed.

Good example:

`Add explanation of pull requests`

Less useful example:

`Update`

A clear commit message makes the project history easier to understand.
