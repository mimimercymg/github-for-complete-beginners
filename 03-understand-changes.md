# Understanding Changes

When you edit a file in a GitHub repository, GitHub keeps track of the changes you make.

## What Is a Change?

A change is any addition, deletion, or modification made to a file.

For example, adding a new sentence to a document is a change.

## Editing a File

To edit a file:

1. Open the repository.
2. Select the file you want to change.
3. Select the **pencil icon** near the top-right of the file.
4. Make your changes in the editor.
5. Select **Preview** to check how the file looks.

## Reviewing Your Changes

Before saving your changes, check that:

* The information is correct.
* Nothing important was removed by mistake.
* The formatting looks correct.
* Only the intended content was changed.

## Saving the Change

When you are finished editing, scroll to the **Commit changes** section.

Enter a short message describing the change.

For example:

`Update beginner guide`

Then select **Commit changes**.

The change will be recorded in the repository's history.

## Why Review Changes?

Reviewing changes before committing helps prevent mistakes and keeps the project's history easier to understand.
