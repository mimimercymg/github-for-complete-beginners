# GitHub for Complete Beginners

A beginner-friendly guide to using GitHub from a web browser.

## About This Guide

This guide explains the basic GitHub workflow for people who are completely new to GitHub.

It focuses on using the GitHub website instead of the command line.

## What You Will Learn

By following this guide, you will learn how to:

- Create a repository
- Create a branch
- Create and edit a file
- Make a commit
- Create a pull request
- Review changes
- Merge a pull request
- Create an issue

## What You Need

- A GitHub account
- A web browser
- An internet connection

## The Basic Workflow

Create a repository → Create a branch → Make a change → Commit the change → Create a pull request → Review the change → Merge the pull request

## Project Status

This is an open-source documentation project designed to make the basic GitHub workflow easier for complete beginners to understand.
