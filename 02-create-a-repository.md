# Creating Your First Repository

A repository is the project space where your files and their history are stored.

## Step 1: Open GitHub

Sign in to your GitHub account and open the GitHub homepage.

## Step 2: Open the New Repository Page

At the top-right corner of GitHub, select the **+** button.

From the menu, select **New repository**.

## Step 3: Choose the Repository Owner

Under **Owner**, select the GitHub account where you want to create the repository.

For a personal project, this will normally be your own GitHub account.

## Step 4: Enter a Repository Name

Find the **Repository name** field.

Enter a name for your project.

For example:

`my-first-repository`

## Step 5: Add a Description

In the **Description** field, enter a short explanation of what the repository is for.

For example:

`A beginner project for learning GitHub.`

## Step 6: Choose the Visibility

Choose **Public** if you want other people to be able to view the repository.

Choose **Private** if you do not want the repository to be publicly visible.

For an open-source project, choose **Public**.

## Step 7: Add a README

Select **Add a README file**.

A README introduces the project and provides useful information about it.

## Step 8: Create the Repository

Select **Create repository**.

GitHub will create the repository and open its main page.

## What You Should See

The repository page will show the repository name, files, branches, and other GitHub features.

You can now begin adding files and making changes to the project.
