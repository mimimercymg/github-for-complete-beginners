# Creating a Branch

A branch is a separate line of work inside a repository.

It allows you to make changes without immediately changing the main branch.

## Why Use a Branch?

Branches are useful when you want to work on a specific change, fix a problem, or add something new.

For example, you could create a branch for adding a new section to a guide.

## Step 1: Open Your Repository

Open the repository on GitHub.

## Step 2: Open the Branch Menu

Above the list of files, find the branch selector.

It will normally show:

`main`

Select it.

## Step 3: Create a New Branch

Enter the name of the branch you want to create.

For this example, use:

`add-github-workflow`

GitHub will show an option to create the branch from `main`.

Select that option.

## Step 4: Check Your Branch

After the branch is created, check the branch selector again.

It should now show:

`add-github-workflow`

This means you are working on the new branch.

## Main Branch vs. Working Branch

The `main` branch is normally the primary branch of the repository.

A working branch is used to make changes before they are added to the main branch.

Using a separate branch makes it easier to review changes before merging them.
