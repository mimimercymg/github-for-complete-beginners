# Creating an Issue

An issue is used to report a problem, suggest an improvement, ask a question, or track a task in a GitHub repository.

## Why Use Issues?

Issues give a project a place to keep track of things that need attention.

For example, you could create an issue when a guide contains unclear instructions.

## Step 1: Open Your Repository

Open the repository on GitHub.

## Step 2: Open the Issues Tab

Near the top of the repository, select **Issues**.

## Step 3: Create a New Issue

Select **New issue**.

## Step 4: Add a Title

Write a short title that clearly explains the problem or request.

For example:

`Add screenshots to the beginner guide`

## Step 5: Describe the Issue

Explain what the problem is and what improvement you are suggesting.

For example:

`The current guide explains the GitHub workflow using text only. Screenshots could make the instructions easier for complete beginners to follow.`

## Step 6: Submit the Issue

Review the information you entered.

Then select **Submit new issue** or the equivalent button shown by GitHub.

The issue is now recorded in the repository and can be discussed or worked on later.

## Issues and Pull Requests

Issues are used to track work or problems.

Pull requests are used to propose changes to the project.

They often work together: an issue can describe what needs to be done, while a pull request can contain the change that solves it.
