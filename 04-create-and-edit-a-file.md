# Creating and Editing a File

Now that a separate branch has been created, you can add a new documentation file.

## Step 1: Check Your Branch

At the top of the repository page, make sure the branch dropdown shows:

`add-getting-started-guide`

Do not continue until you are on the correct branch.

## Step 2: Open the Add File Menu

Above the list of files, select **Add file**.

From the menu, select **Create new file**.

## Step 3: Name the File

A field for the file name will appear.

Enter:

`getting-started.md`

The `.md` extension means the file uses Markdown.

## Step 4: Add the Content

Enter the following:

# Getting Started with GitHub

GitHub is a platform where Git repositories can be stored online and used for collaboration.

## What Is a Repository?

A repository is the project space where files and their change history are stored.

## What Is a Branch?

A branch is a separate version of the project where changes can be made without immediately changing the main branch.

## What Is a Commit?

A commit records a snapshot of changes made to files in the repository.

## What Is a Pull Request?

A pull request allows changes made on one branch to be proposed for review before they are merged into another branch.

## Step 5: Preview the File

Before saving the file, select **Preview**.

Check how the Markdown is displayed.

Make sure the headings and text look correct.

## Step 6: Save the File

Scroll down to the **Commit changes** section.

GitHub will provide a commit message field.

You can leave the suggested message or replace it with:

`Add getting started guide`

Make sure the change is being committed to:

`add-getting-started-guide`

Then select **Commit changes**.

Your new file has now been added to the branch.

## Step 7: Check the File

Return to the repository file list.

You should now see:

`getting-started.md`

Select the file to open it.

The file is now part of your repository.

This guide uses the GitHub website instead of the command line.
